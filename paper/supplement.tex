\section*{S1. Every system on every board}
Cost per task is in dollars under one price table with each model call counted once. ``Front.'' marks the observed frontier, ``Set'' the frontier confidence set at the 5\% level, ``Fixed'' the same set with costs fixed at their means, ``Rob.'' the tie-robust set, ``Stab.'' the bootstrap frontier stability, and ``Best'' the confidence set of the most accurate system. The rival lead (``Lead'') is the strongest cheaper-or-equal system's accuracy minus this system's, in paired standard errors; a system leaves the frontier set when its rival lead exceeds the board's simultaneous margin.

\section*{S11. The frontier set against six alternatives}

\caption{Seven ways to turn the same board into a set, on known truth (\NumValR{} boards per scenario, per-task costs).
