# Task-group labels used by `src/cluster_check.py`

`scienceagentbench_groups.json` holds four columns of the public task dataset `osunlp/ScienceAgentBench` (Hugging Face, licence CC BY 4.0): `instance_id`, `domain`, `subtask_categories` and `github_name`. The first two identify the task and its science domain. `github_name` is the source repository of the task and is the grouping used in the paper. Credit: ScienceAgentBench, Chen et al., Ohio State University NLP group.

Online-Mind2Web's website labels sit in a gated dataset and are not included.
